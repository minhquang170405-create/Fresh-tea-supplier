# Guidance for AI coding agents

Read `DESIGN.md` before changing this website. Preserve its TS 567 visual concept, content constraints, four-language structure, and explicit placeholders.

The site is plain HTML, CSS, and JavaScript. Keep that stack unless the owner asks to change it. Make focused changes in `index.html`, `en.html`, `zh-cn.html`, `zh-tw.html`, `styles.css`, and `script.js`; update translated UI text consistently. Do not copy a third-party brand's `DESIGN.md` verbatim or introduce a full component framework just to adjust this static page.

Before publishing, check responsive layout, contrast, keyboard access, language switching, fragment links, and contact-preview safety as specified in `DESIGN.md`. Document any remaining placeholder or missing real contact channel clearly.
