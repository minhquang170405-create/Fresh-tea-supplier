# TS 567 — Trà Mã Dọ

Static website for Trà Biển TS 567 – Trà Mã Dọ. Open `index.html` through a local HTTP server. The CSS, JavaScript, Vietnamese fonts, and logo are included locally.

The sticky header has a language dropdown linking four complete static pages: Vietnamese (`index.html`), English (`en.html`), Simplified Chinese (`zh-cn.html`), and Traditional Chinese for Taiwan (`zh-tw.html`). Each page includes its own translated metadata, accessible labels, placeholders, and form preview message. `hreflang` links connect the language variants.

The site presents the Cù Mông origin, hand harvesting, natural flavor, and an approximate harvest of 20 kg of fresh tea leaves every two months, as supplied by the owner. This fresh-leaf harvest figure is not a finished-tea yield or an order capacity. The Switzerland section describes an intended audience, not an established export market.

Product imagery, garden imagery, packaging, unconfirmed specifications, partners, and contact details remain clearly marked placeholders. Laboratory results and scans also remain placeholders until approved for publication. The enquiry form is a preview and does not send or save data.

The public website is published from the `main` branch with GitHub Pages at `https://minhquang170405-create.github.io/Fresh-tea-supplier/`.

`DESIGN.md` records the TS 567 concept and content limits. `DESIGN_SYSTEM.md` specifies the implemented tokens, component behavior, QA checks, and the downloaded design-rule sources adapted for this site. `AGENTS.md` directs future AI coding agents to both guides before editing.
